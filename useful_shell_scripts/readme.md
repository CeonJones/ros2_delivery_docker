# Shell scripts
This repo contains useful shell scripts to automate some things for you

## Run Arduplane Host
- This shell script is used to run Ardupilot SITL on your host computer (typically not your embedded system). First move the shell script to your host computer where you are running SITL. THen in the shell script you might need to change the out command from the current ip address to the ip address of where your companion computer is.

## Run Mavros
This runs the mavros protocol for your simulation set up
